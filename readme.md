Weather API

Асинхронный REST-сервис для получения и кэширования прогнозов погоды через
провайдер Open-Meteo. Поддерживает персональные списки городов для
пользователей, фоновое обновление данных и подбор ближайшего по времени
прогноза.

Особенности архитектуры

  - Фоновый воркер: периодически (каждые 15 минут) обновляет суточные прогнозы
    для всех сохранённых городов.
  - Интеллектуальный поиск времени: при запросе времени суток сервис находит и
    возвращает ближайший 15-минутный интервал прогноза.
  - Кэширование данных: минимизирует количество внешних запросов к Open-Meteo за
    счёт сохранения структуры прогнозов в SQLite.
  - Гибкая выборка параметров: возможность отключать ненужные метеоданные через
    query-параметры.

Стек технологий

  - Python 3.10+
  - FastAPI / Uvicorn — веб-слой и маршрутизация
  - SQLAlchemy 2.0 (Async) + aiosqlite — асинхронный ORM и работа с базой данных
  - HTTPX — асинхронные HTTP-запросы
  - Pydantic v2 — валидация схем и типов
  - Pytest + pytest-asyncio — модульное и интеграционное тестирование

Установка и запуск

1. Подготовка окружения

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ПАПКА_ПРОЕКТА>

python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

2. Установка зависимостей

```bash
pip install fastapi uvicorn httpx sqlalchemy aiosqlite pydantic pytest pytest-asyncio
```

3. Запуск сервиса

```bash
uvicorn main:app --reload
```

Сервер запустится по адресу http://127.0.0.1:8000.
Документация OpenAPI доступна по пути /docs или /redoc.

Тестирование

Тесты используют изолированную базу данных SQLite в памяти (:memory:) и мокируют
внешние сетевые вызовы к Open-Meteo.

# Запуск с подробным выводом
pytest unit_tests.py -v

Основные эндпоинты

| Метод  | Путь                                   | Описание                                                |
| ------ | -------------------------------------- | ------------------------------------------------------- |
| `GET`  | `/weather/current`                     | Текущая погода по координатам (`latitude`, `longitude`) |
| `POST` | `/users`                               | Регистрация нового пользователя                         |
| `POST` | `/users/{user_id}/cities`              | Привязка города с координатами к пользователю           |
| `GET`  | `/users/{user_id}/cities`              | Список городов пользователя                             |
| `GET`  | `/users/{user_id}/weather/{city_name}` | Прогноз погоды для города с поиском ближайшего времени  |

Пример запроса погоды

curl -X GET "http://127.0.0.1:8000/users/1/weather/moscow?time=14:37&temperature=true&humidity=true&wind_speed=false&precipitation=false"

Ответ:

{
  "city": "Moscow",
  "requested_time": "14:37",
  "time": "14:30",
  "temperature": 16.0,
  "humidity": 55
}
